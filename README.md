# E-Commerce Dashboard using Microsoft Power BI

## Project Overview
This project focuses on e-commerce data analysis and dashboard development using Microsoft Power BI. It covers data modelling, KPI development, inventory and delivery analysis, supplier and transportation analytics, and warehouse performance.

## Project Milestones

### Milestone 1: Data Modelling & KPI Foundation
- Data import and data modelling
- KPI and DAX measure creation
- Initial dashboard development

### Milestone 2: Inventory & Delivery Analytics
- Inventory analysis
- Delivery and shipment status analysis
- Performance indicators

### Milestone 3: Supplier & Transportation Analytics
- Supplier performance analysis
- Transportation analytics
- Supporting sample data where required

### Milestone 4: Warehouse Analytics & Final Dashboard
- Warehouse efficiency analysis
- Executive overview dashboard
- Dashboard optimization

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- CSV datasets
