# Project Documentation

This folder contains the project documentation for **E-Commerce Dashboard using Microsoft Power BI**.

## Documentation Contents

The documentation explains the project objectives, methodology, milestone activities, dashboard development, and key findings.

### Project Milestones

- **Milestone 1 – Data Modelling & KPI Foundation:** Data preparation, data modelling, and KPI development.
- **Milestone 2 – Inventory & Delivery Analytics:** Inventory performance, shipment status, and delivery analysis.
- **Milestone 3 – Supplier & Transportation Analytics:** Supplier performance, transportation analysis, and supporting sample data.
- **Milestone 4 – Warehouse Analytics & Final Dashboard:** Warehouse efficiency, executive overview, and dashboard optimization.
