# Power BI Dashboard Screenshots

This folder contains screenshots of the dashboards developed for the **E-Commerce Dashboard using Microsoft Power BI** project.

## Project Milestones

### Milestone 1: Data Modelling & KPI Foundation
Screenshots showing data modelling, KPI cards, DAX measures, and the initial dashboard.

### Milestone 2: Inventory & Delivery Analytics
Screenshots showing inventory analysis, shipment status, and delivery performance.

### Milestone 3: Supplier & Transportation Analytics
Screenshots showing supplier performance, transportation analysis, and shipment insights.

### Milestone 4: Warehouse Analytics & Final Dashboard
Screenshots showing warehouse efficiency, executive overview, and the final dashboard.

## Purpose

These screenshots provide visual evidence of the dashboards and analytical results developed during each milestone.
